Defining and Using Functions

الدوال هي كتل من الكود قابلة لإعادة الاستخدام تُنفذ مهمة محددة. يتم تعريفها باستخدام الكلمة المفتاحية def. 

# تعريف دالة بسيطة تستقبل معامل واحد
def greet(name):
    print(f"Hello, {name}!")

# تعريف دالة تقوم بإرجاع قيمة
def add_numbers(x, y):
    return x + y

# استدعاء الدالة الأولى
greet("Ahmed")

# استدعاء الدالة الثانية وحفظ النتيجة في متغير
sum_result = add_numbers(5, 3)
print(f"The sum is: {sum_result}")
Hello, Ahmed!
The sum is: 8
